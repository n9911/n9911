# n9911: включение обновлений

1. Загрузить содержимое этой папки в корень профильного репозитория n9911/n9911: README.md, index.html, src, .github и по желанию короткий .gitignore. Существующий LICENSE сохраняется.
2. Settings → Pages → Build and deployment → Source: GitHub Actions.
3. Actions → Refresh profile and publish Pages → Run workflow на основной ветке.
4. После успешной сборки открыть https://n9911.github.io/n9911/ и проверить время на четырёх графиках. README берёт эти же SVG с Pages. До первого успешного запуска внешние изображения в README могут не открываться; локальная HTML-страница содержит сохранённый предварительный снимок.

Расписание: 00:17, 06:17, 12:17, 18:17 UTC (cron 17 */6 * * *). Запуск возможен с задержкой; GitHub отключает расписание публичного репозитория после 60 дней без активности. Включить его повторно можно в Actions. У GitHub Events задержка до шести часов; поток ограничен 300 событиями за 30 дней. Кэш изображений GitHub README тоже может задержать отображение нового SVG. Точное время снимка напечатано на картинке.

Workflow читает репозитории с contents: read и публикует только Pages-артефакт с pages: write/id-token: write. Он не делает коммитов, push, не меняет ветки, теги и README в Git. Токен runner используется только для публичных GET и не сохраняется в файлы. Активацию и все удалённые настройки выполняет Денис вручную. Агент ничего не активирует.

Портреты и иллюстрации сохраняются; обновляются четыре информационных графика и JSON. Подписи навыков и подборка инструментов — редакционный материал, меняются вместе с исходниками профиля. CSS: src/styles/profile.css. Сборщики: src/scripts/metrics.mjs и build.mjs; браузерный код: site.js. SCSS и npm-зависимости для этого небольшого сайта не нужны. README.md остаётся в корне, иначе GitHub не покажет его в профиле. index.html работает как сайт после включения Pages.
